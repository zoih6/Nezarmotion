# القصيدة التي تصير صباحًا

فيلم موشن جرافيك موسيقي عمودي، من كلمات الشاعر الأنيق **نزار القدسي**، مع خاتمة **ومض — استديو الإنتاج والإبداع الفني**.

## الإخراج

خيط ضوء يتحول من أثر قلم إلى تضاريس وسحاب وغزال وزهور وشروق. المشاهد تُرسم وتتحرك برمجيًا، مع مكونات مستقلة للبتلات والأوراق ومكونات الشعار الأصلية. لا توجد لقطات مأخوذة من الفيديوهات المرجعية ولا شخصية مولدة تمثل الشاعر.

- 120 ثانية، 1080×1920، 30fps.
- HTML Canvas + Playwright + FFmpeg، مع دالة `window.seek(t)` حتمية.
- Spring motion، مسارات Bézier، نمو أوراق، أقنعة تشكيل، وتداخل طبقات.
- الأغنية المرفقة من البداية، دون تغيير مواضع العبارات.
- نصوص عربية بخطوط محلية، لا نص داخل صور مولدة.
- ثلاث جولات نقد وإصلاح قبل التصيير النهائي، وفحص تقني للملف النهائي بعده.

## الملفات

- `index.html` + `film.js`: برنامج الفيلم.
- `assets/data.js`: الزمن والإيقاع والمشاهد؛ `assets/lyrics.json`: نصوص العبارات.
- `assets/*.webp`: أصول قصاصات موثقة ومعالَجة؛ الشعار الأصلي لم يُولّد من جديد.
- `assets/fonts/`: الخطوط وتراخيص OFL.
- `docs/production-sheet.csv`: جدول الإنتاج الكامل القابل للتحرير.
- `docs/shotlist.md` و`docs/storyboard.md`: مخطط اللقطات.
- `docs/critique.md`: ما تغير في كل جولة مراجعة.
- `docs/qa.json`: نتائج اختبار الحتمية والعربية والمساحة الآمنة والتوقيت.
- `docs/audio-report.json`: قياسات الصوت النهائي.
- `../deliverables/`: الفيديو والبوستر والـcontact sheet وملف التوقيت.

الأغنية وملف الشعار مصدران أصليان في جذر المستودع، ولا تُنسخ منهما نسخ إضافية داخل المشروع. المقاطع المرجعية للاطلاع فقط وليست ضمن الفيديو النهائي.

## إعادة التصيير

متطلبات النظام: Node.js 20+، Python 3، FFmpeg وFFprobe.

```bash
cd production
npm ci
npx playwright install chromium
# Linux فقط، إذا كانت مكتبات المتصفح ناقصة:
npx playwright install-deps chromium
npm test
npm run render
```

يُخرج الأمر نسخة 1080p ونسخة 720p خفيفة بالصوت نفسه.

المخرجات الوسيطة تذهب إلى `production/out/` وهو مستثنى من Git. يمكن حذفه بعد إخراج الفيديو. لا تُحفظ آلاف الإطارات على القرص؛ تُمرّر مباشرة من Canvas إلى FFmpeg.

للمعاينة بعد التصيير:

```bash
npm run preview
```

الخادم يقبل اسم مضيف المعاينة ويستمع إلى `0.0.0.0:3000`. المعاينة تستخدم ملفات محلية وروابط نسبية فقط.

## إعادة تحليل الإيقاع (اختياري)

الأرقام المقاسة محفوظة بالفعل في `assets/beats.json` و`assets/data.js`. لإعادة تحليل الأغنية:

```bash
pip install numpy librosa soundfile
python scripts/beats.py ../الأغنية.mp3 > assets/beats.json
```

ملف الأغنية مدته 120.024 ثانية؛ استخدمت أول 120 ثانية مع تلاشي 0.85 ثانية في النهاية. توقيت ملف SRT هو توقيت **العبارات الذي قدمه المستخدم**، وليس ادعاء محاذاة صوتية على مستوى كل كلمة. الكلمات موجودة داخل الفيديو بالفعل؛ SRT مرجع اختياري ولا يُضاف فوقها عند النشر.
