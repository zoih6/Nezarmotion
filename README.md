## الفكرة الإبداعية: «قصيدة الفجر»

القصيدة كلها رحلة من الليل إلى الشروق، فبُني الفيديو على **سيناريو لوني** يتبع الكلمات:
**ليل نيلي ← فجر وردي ← شروق ذهبي ← ورق كريمي بألوان ومض**.

الأسلوب **كولاج ورقي سينمائي**: ورق ممزّق الحواف، صور حقيقية مقصوصة بإطار ورقي (غزال، زهور، أغصان)،
وطبقات تتحرك على الإيقاع. الكلمات تظهر **بخط الرقعة** متزامنة مع الغناء، والكلمة المفتاحية في كل بيت تُبرز على شريط ذهبي.

## المواصفات

- 1080×1920 · 30fps · H.264 + AAC 48kHz · المدة 2:00 (مطابقة للأغنية)
- الصوت مضبوط على **−14 LUFS** (معيار المنصات)
- الخطوط: Aref Ruqaa للعرض، وAlexandria للنصوص الصغيرة (رخصة OFL)
- التحريك: نوابض فيزيائية، وكل إطار دالة خالصة للزمن (تصيير متطابق ومقسّم)
- الأصول: صور مولّدة خصيصاً بالذكاء الاصطناعي (`production/assets/gen`)، وقص يدوي بالخوارزميات، وشعار ومض مفكّك لـ8 طبقات

## بنية المستودع

```
الأغنية.mp3 · الشعار · المقطع الأصلي · المراجع      ← الملفات الأصلية
deliverables/      ← النسخة الخفيفة + البوستر + ورقة اللقطات
production/film/   ← كود الفيلم (index.html · lib.js · film.js · data.js) والأصول والخطوط
production/tools/  ← أدوات القص وتفكيك الشعار والتصيير
```

**إعادة التصيير:** `cd production && npm i playwright && bash tools/render_all.sh`، ثم الدمج مع الأغنية.
