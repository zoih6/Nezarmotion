# Nezarmotion

مستودع عام يضم ملفات الحركة/الفيديو والمهارة المرفقة `motion-reel`.

## المحتويات

- مقاطع فيديو مرجعية وتجريبية.
- ملف صوتي وصورة.
- `motion-reel/`: مهارة لإنشاء فيديوهات motion graphics قابلة للتصيير من الكود باستخدام HTML Canvas وPlaywright وFFmpeg.
- `motion-reel-skill.zip`: النسخة المضغوطة الأصلية من المهارة.

## المهارة

توجد تعليمات المهارة في [`motion-reel/SKILL.md`](motion-reel/SKILL.md)، وتشمل عقد التصيير، القوالب، أدوات الحركة، والمؤثرات الصوتية.

> ملاحظة: تأكد من امتلاك الحقوق اللازمة لأي فيديو أو صوت قبل إعادة نشره أو استخدامه تجاريًا.
